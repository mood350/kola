# KOLA Mobile

Application React Native TypeScript créée à partir des écrans Stitch fournis.

## Démarrage

```bash
npm install
npm start
```

Si le disque `C:` est plein sous Windows, utilisez un cache situé sur `D:` :

```bash
npm install --cache D:\npm-cache
npm start
```

Dans Expo : appuyer sur `a` pour Android, `i` pour iOS, ou scanner le QR code avec Expo Go.

## Écrans

- Accueil / portefeuille
- Coffres d'épargne programmée
- Scanner QR de démonstration
- Score de crédit et simulateur de microprêt
- Transactions programmées

Les données sont locales et prêtes à être remplacées par les API du backend.
